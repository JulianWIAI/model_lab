## Section 8: Known doubts and deferred items

1. **bellmanError() removed** — the original implementation computed `|Q(s,a) − γ·max Q(s,a)|` using the same state instead of next state, and omitted reward r. The function was removed rather than patched since it requires stored transition dynamics not available in the generic RLModel. A caller who needs convergence monitoring should check Bellman residuals against stored transitions.

2. **LOW-2 (auction revenue equivalence test)** — the test named "revenue equivalence" only re-asserts `E[R]=1/3` (identical to the preceding test) rather than comparing first-price and second-price revenues. Deferred — behavior is correct; only the test label is misleading. Noted for future improvement.

3. **LOW-3 (gambler's ruin test)** — `2/8 === 0.25` is pure arithmetic and exercises no model code. Deferred — low priority.

4. **LOW-4 (key collision in RLModel.Q())** — key `${s},${a}` can collide if state or action names contain commas. No current test exercises this. Deferred — the corridor MDP uses integer states; the hazard is only for custom MDPs.

5. **LOW-5 (bidCurve returns nPoints+1 points)** — `AuctionModel.bidCurve(200)` returns 201 points. Asymmetric with BV convention. Deferred — no current caller assumes length === nPoints.

6. **Weber-Fechner modality table** (Phase 5 legacy) — still flagged as unverified illustrative values. Not touched in Phase 10.
