Model Lab

Live models you can push until they break. Every simulation follows the same loop: commit to a prediction, run it, find where the model fails, then explain what you saw in one sentence.

1Predict2Run3Break it4Explain

    The lab did not start. If you opened index.html by double-clicking it, the browser blocks JavaScript modules. Start a small local server instead, for example python -m http.server 8000 in this folder, then open http://localhost:8000. See README.md.

    Open source. Every simulation lives in its own folder under js/benches, split into a model (the science), a view (the drawing) and a bench (the controls).
